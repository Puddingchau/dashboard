# 害羞動物園（Quiet Habitat）

一個給老師在班房投影使用的安靜工具。電腦咪高峰會量度班房的音量：同學夠安靜，害羞的動物就會一隻一隻走出來留下；如果持續太吵，場景會變模糊，動物也可能會走開。

這是一件**原創**的課堂工具，靈感來自「用音量讓動物出現」這個課堂管理想法，但名稱、畫面、角色與程式都是重新設計，並不是 Shy Safari，也不使用他們的素材或品牌。

## 點樣打開

咪高峰需要安全的網頁環境（`localhost` 或 HTTPS）。**不要**直接用檔案方式（`file://`）打開，否則瀏覽器通常不會允許使用咪高峰。

在這資料夾開一個本機伺服器，例如：

```bash
cd quiet-habitat
python3 -m http.server 8080
```

然後用瀏覽器打開：

[http://localhost:8080/](http://localhost:8080/)

（其他靜態伺服器也可以，例如 `npx serve` 或 VS Code / Cursor 的 Live Preview。）

建議用最新的 Chrome、Edge、Firefox 或 Safari，並將視窗或投影設成 16:9（1280×720 或 1920×1080 都很合適）。

## 課堂點樣用

1. 開啟網頁，揀一個主題（預設是草原）。
2. 按「開始」，允許瀏覽器使用咪高峰。如果未能允許，可以用「示範模式」先預覽場面（畫面按鈕，或鍵盤 `1` / `2` / `3`）。
3. 設定音量目標：
   - **安靜**：全班靜靜地做功課
   - **自行工作（輕聲）**：可以輕輕細語
   - **分組討論**：小組輕聲交談
   - 也可以直接拖動音量條上的直向標記。
4. 開始前可設定課堂時間（預設 15 分鐘；也可以揀 5 / 10 / 20 / 30 分鐘、自訂，或「不限時」）。上課時畫面上方會顯示倒數（分：秒），同學從教室後面都睇到。
5. 讓同學安靜作業。大約 5–10 秒後第一隻動物會出現，之後會按你選的節奏一隻隻到來。
6. 短促的聲響（關門、掉書）不會即時算太吵；要持續大聲一會兒才會觸發。
7. 太吵時（預設），場景會蒙上一層主題相關的霧氣，動物會一隻隻離開。你也可以在設定改成「暫停場面」：動物停住，但不會被帶走。
8. 安靜回來之後，大約 3 秒霧氣會散去，動物可以再次出現。
9. 老師可撳右下角齒輪，或撳音量條，打開設定、圖鑑、校正同轉主題。`Esc` 可離開全畫面或關閉視窗。時間到時動物會留在畫面；老師可以再開多 5 分鐘，或者結束這回。

課堂前想先睇效果，可在「設定」揀 **試玩** 節奏（大約每 6 至 8 秒一隻）。正式上課建議用「一般」（約 45 秒一隻，預設）、「輕鬆」（約 2 分鐘）或「輕快」（約 20 秒）。


## 學校 SMART Board

這套工具是為課堂電子白板設計的，按鈕同主題卡都夠大，用手指就可以揀主題、按開始、調音量。

1. 喺**接住 SMART Board 嗰部電腦**用 Chrome、Edge 或 Safari 打開呢個網頁（需要 HTTPS 或本機伺服器，咪高峰先會運作）。
2. 按右下角全畫面。
3. 允許嗰部電腦使用咪高峰，並將手提電腦／外置咪對住班房（唔好遮住或指向走廊）。
4. 用手指揀主題、設定課堂時間（預設 15 分鐘），再按「開始」。上課期間可直接撳音量條下面嘅「安靜／自行工作／分組討論」，或拖動音量標記。倒數鐘會顯示在畫面上方。
5. 同學只需要望住白板，唔使開自己的平板或電話。

如果學校電腦唔方便開本機伺服器，可以把呢個資料夾放到一個 HTTPS 網頁（例如 GitHub Pages）再打開。

## 電話

同一個連結也可以在電話打開（直向或橫向都可以）。用 Safari 或 Chrome 打開後，允許電話使用咪高峰；老師亦可以把網頁加到主畫面，之後一撳就開。課堂投影仍然建議用接住 SMART Board 嗰部電腦，同學唔使開自己的裝置。

## 主題

草原、珊瑚礁、深空、恐龍時代、森林、叢林、極地、南瓜園。每個主題都有十多位原創朋友；當中三位是稀有的，不是每一次都能遇見。

南瓜園場景裡有木牌寫著「南瓜園」，適合節慶或氣氛較輕鬆的課時。

## 私隱

- 瀏覽器只會在這隻電腦即時量度音量。
- **不會錄音**，也不會把聲音或音量資料傳去其他伺服器。
- 設定、語言同圖鑑記錄只儲存在這隻電腦的 `localStorage`。
- 校正咪高峰（5 秒安靜 + 5 秒平常說話）同樣只在本機進行，用來配合這個班房的回音同咪高峰靈敏度。

## 檔案

- `index.html` — 頁面
- `css/styles.css` — 樣式
- `js/i18n.js` — 繁體中文（香港）與英文文案
- `js/art.js` — 原創 SVG 動物與圖示
- `js/themes.js` — 八個主題場景與名單
- `js/audio.js` — 咪高峰量度與示範模式
- `js/engine.js` — 出現、太吵、離開的節奏
- `js/app.js` — 畫面操作與儲存

無需安裝、無需編譯、無需付費應用程式介面。用任何靜態網頁伺服器打開即可。
